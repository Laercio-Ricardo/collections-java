
# 🎯 Sistema de Gerenciamento de Tarefas (Java CLI)

Análise arquitetural, mapeamento de estruturas de dados e documentação do desafio prático de **Collections (List / ArrayList)** desenvolvido para o **Bootcamp Santander / DIO**.

---

## 📦 1. O PROJETO (Visão Geral)

A aplicação consiste em um sistema de console (CLI) projetado para gerenciar uma lista dinâmica de tarefas de forma eficiente. O principal objetivo do projeto foi aplicar os pilares da **Programação Orientada a Objetos (POO)** e dominar a manipulação de dados em memória utilizando o ecossistema de estruturas de dados nativas do Java.

Este repositório documenta a evolução da lógica algorítmica para uma engenharia de software limpa, padronizada e modular — servindo como base conceitual indispensável para o desenvolvimento futuro de APIs robustas com o framework **Spring Boot**.

---

## 🛠️ 2. AMBIENTE DE DESENVOLVIMENTO

Para garantir a máxima performance e compatibilidade com os recursos mais recentes da linguagem, o ecossistema do projeto foi configurado com as seguintes especificações:

* **Linguagem de Programação:** Java 26 (OpenJDK)
* **Ambiente de Desenvolvimento (IDE):** IntelliJ IDEA 2026.1
* **Estrutura de Dados Utilizada:** `java.util.ArrayList`
* **Paradigma de Desenvolvimento:** Orientação a Objetos (POO)
* **Codificação de Arquivos:** UTF-8

---

## 📐 3. ARQUITETURA DE CLASSES

O sistema foi estruturado seguindo o princípio da responsabilidade única, dividindo o modelo de dados e o motor de regras de negócio dentro do pacote `tarefas`.
